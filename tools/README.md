# Shared tools

- `flashing/`: programming and device setup helpers.
- `simulation/`: cross-discipline simulation helpers.
- `analysis/`: shared data analysis helpers.

These are reserved locations; no executable tools are provided yet. Keep
area-specific helpers with their area, such as `mechanical/tools/`. Document
dependencies, inputs, outputs, and invocation when adding a tool. Use relative
paths or explicit parameters instead of personal absolute filesystem paths.
