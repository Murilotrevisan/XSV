# XSV
Xtreme Surface Vessel

Projeto de barco de aproximadamente R$100 para batalha e rampa em ambiente controlado. Deve subir/sair pela rampa, saltar e evitar dano à eletrônica por entrada de água. Priorizar materiais reaproveitados e construção simples.

Disponível: ESP32-C5 contabilizada a R$13 e impressora 3D. Restam R$87 para o restante do sistema; incluir o filamento consumido no custo.

Não há requisito de operar invertido, autoendireitar, manter flutuação após avaria, detectar vazamento ou registrar falhas. Virar já implica perda de pontos. Um recipiente PET com vedação simples é uma solução candidata para a eletrônica.

O [estudo comparativo interativo](docs/estudo-comparativo-xsv.html) reúne seis construções, desenhos, curvas de estabilidade, forças equivalentes, energia na rampa, salto e orçamento ajustável. Baixe ou abra o HTML no navegador; funciona offline e exporta cálculos em CSV. Premissas, limitações e fontes estão no próprio documento.

O [código de cálculo e os testes](docs/estudo-xsv/README.md) permitem reproduzir os resultados. O [estudo qualitativo anterior](docs/pesquisa-arquiteturas-navais-2026-09-27.md) permanece como registro da pesquisa de construção econômica; os números e as comparações quantitativas estão no HTML.
