# Hardware

Electronics design sources and supporting material. Read
[AGENTS.md](../AGENTS.md) and the [shared context](../docs/CONTEXT.md) first.

- `schematics/`: editable electrical schematics and selected viewable exports.
- `pcb/`: board design sources.
- `bom/`: bills of materials tied to design revisions.
- `datasheets/`: a reference index with manufacturer links; include documents
  only when redistribution is permitted and useful to the project.

No components, board toolchain, or electrical architecture have been selected.
Keep editable sources authoritative and identify the revision behind exports.
When changing electrical behavior, provide the relevant electrical diagram.
When changing geometry or mounting, provide dimensioned drawings and update the
shared mechanical interface. Record actual checks and distinguish unbuilt designs
from physically verified hardware.
